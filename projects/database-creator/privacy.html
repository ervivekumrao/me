Privacy Policy

Last updated: June 10, 2026

Database Creator ("the Tool") is an open-source automation utility.

1. Local Execution Only

The Tool operates entirely on your local machine. It does not collect or transmit any database configurations, credentials, or machine identifiers to any external server.

2. Database Credentials

Any credentials configured in Database.properties or passed via command-line arguments are used solely to configure the local Docker containers. These values are never shared or uploaded.

3. Docker Integration

The Tool interacts with your local Docker daemon to pull official database images and manage containers. This interaction follows standard Docker security protocols.

4. Contact Us

For any privacy-related inquiries, please contact manuscriptcode@gmail.com.
