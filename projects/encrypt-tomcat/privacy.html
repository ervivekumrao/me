Privacy Policy

Last updated: June 10, 2026

Encrypt Tomcat Connection Pool ("the Tool") is a security utility.

1. No Data Collection

The Tool does not collect, store, or transmit any encrypted or decrypted data. All encryption and decryption operations are performed locally on your machine or within your server's runtime environment.

2. Encryption Keys

The Tool uses keys provided in the source code or modified by the user. These keys are never shared or transmitted. It is the user's responsibility to manage and protect their custom encryption keys.

3. Server Integration

When integrated into Tomcat, the Tool only processes attributes defined in your local configuration files. No data is sent to any external monitoring or logging service by the Tool itself.

4. Contact Us

For any questions, please contact manuscriptcode@gmail.com.
