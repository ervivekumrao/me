SpinDB

A fast, unified developer CLI (spinctl) for spinning up 13 containerized databases, in-memory caches, and lakehouse engines using Podman (default, secure, rootless) with seamless automatic fallback to Docker.

spinctl CLI Rootless Podman Docker Fallback 13 Database Engines pgvector & AI ClickHouse OLAP DuckDB / Spark Emulators OCI Healthchecks
View on GitHub

Developer Productivity & Multi-Engine Power

🦭 Rootless Podman & Docker Fallback

Daemonless and rootless by default for superior system security. Automatically falls back to Docker if Podman is absent. Built-in --preflight checks output exact OS package installation commands.

🏢 13 Engines Supported

Spin up PostgreSQL, pgvector (AI embeddings), MySQL, MariaDB, SQL Server 2022, Oracle Free, IBM DB2, MongoDB, Redis/Valkey, ClickHouse (OLAP), CockroachDB, Snowflake Emulator (DuckDB), and Databricks (Spark + Delta Lake).

🩺 Port-Aware OCI Healthchecks

Monitors internal container readiness via port-aware OCI health probes, tracking starting and healthy status transitions so applications never connect to an unready socket.

🔌 Auto Port Allocation & Sequential Naming

Automatically discovers free host ports to eliminate port collision errors. Generates clear, collision-free container instance identifiers linked to the allocated port (e.g., mysql-3306, postgres-5432).

🔄 Multi-Variant & Version Discovery

Dynamic container version discovery (--list-versions) backed by TTL caching. Launch specific database major and minor versions effortlessly without manual tag hunting.

🛡️ Localhost Security & Storage Volumes

Binds to 127.0.0.1 by default to prevent unauthorized network exposure on shared Wi-Fi. Easily switch to ephemeral container storage or persistent host mount directories with -d.

Quickstart with spinctl

Run a single command to spin up any database environment instantly.

1

Preflight System Verification

./bin/spinctl --preflight
2

Spin Up PostgreSQL with pgvector AI Embeddings

./bin/spinctl -t pgvector -p 5432 -n dev-pgvector
3

Spin Up Redis Cache or ClickHouse Analytics

./bin/spinctl -t redis -p 6379 -n dev-redis
./bin/spinctl -t clickhouse -p 8123 -n dev-olap
