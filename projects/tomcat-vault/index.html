Tomcat Vault

Enterprise-grade cryptographic credential manager, diagnostic verifier, and JNDI DataSource factory for Apache Tomcat connection pools. Eliminates cleartext database credentials from context.xml and server.xml using authenticated AES-256-GCM encryption, dynamic IVs, universal connection pool adapters, and cloud secret connectors.

Tomcat 7–11 Java 8–25+ AES-256-GCM ENC(...) Envelope HikariCP & DBCP2 AWS & HashiCorp Vault Zero-Restart Reloader JMX Credential Masking

Enterprise Infrastructure Hardening

🔐 Modern Authenticated Encryption

Uses 256-bit AES in Galois/Counter Mode (GCM) with 12-byte cryptographically secure random IVs and 128-bit authentication tags. Adopts standard ENC(...) envelopes while preserving 100% backward compatibility with legacy ciphertexts.

🏊 Universal Connection Pool Support

Dedicated high-performance factories for HikariCP (VaultHikariDataSourceFactory), Tomcat DBCP2, Tomcat JDBC, and a Universal Adapter compatible with Vibur DBCP and C3P0.

☁️ Cloud & Enterprise Secret Connectors

Direct dynamic secret resolution for AWS Secrets Manager (AWS_SECRET(...)), HashiCorp Vault (VAULT(...)), Azure Key Vault, and GCP Secret Manager with in-memory TTL caching.

🔄 Dynamic Credential Refresh Coordinator

VaultCredentialReloader coordinates in-flight credential rotation by evicting stale pooled connections and re-authenticating against new credentials without bouncing the Tomcat server.

🛡️ JMX Credential Masking & K8s Auto-Reload

VaultJmxSanitizer automatically masks passwords and connection string secrets with ****** in JMX MBeans (Prometheus/VisualVM). Dynamically watches and reloads mounted Kubernetes Secret files.

🩺 Connection Verification & Dry-Run CLI

Validate encrypted credentials, decrypt test envelopes, and verify live database connectivity directly against context.xml prior to server deployment using the standalone verification CLI.

Seamless JNDI Pool Configuration

Zero application code changes — configure transparently in context.xml.

Encrypted HikariCP Resource in context.xml

<Resource name="jdbc/AppDB"
          auth="Container"
          type="javax.sql.DataSource"
          factory="umrao.tomcat.vault.VaultHikariDataSourceFactory"
          driverClassName="org.postgresql.Driver"
          jdbcUrl="jdbc:postgresql://db.corp.internal:5432/app"
          username="app_user"
          password="ENC(AQIDBAUGBwgJCgsMDQ4PEBESExQVFhcYGRobHB0=)"
          maximumPoolSize="30" />
