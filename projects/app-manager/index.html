Deployment Guide

Steps to activate enterprise-level management on your devices.

1

Device Preparation

For full management, the device should be factory reset. During the initial setup, use the "afw#setup" identifier or a specialized QR code.

2

Grant Admin Rights

Launch the App Manager and follow the prompts to grant Device Administrator status. This enables the core security policy engine.

3

Configure Policy

Access the dashboard to select which system apps to freeze and which hardware restrictions to enforce (e.g., Disable Camera, Prevent Factory Reset).

4

Deploy & Monitor

Once configured, the device is locked down. Policies can be updated remotely if integrated with an EMM server backend.
