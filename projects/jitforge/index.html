Core Capabilities & Architecture

⚡ In-Memory Compilation & Zero Coupling

Zero interface or base class constraints. Pass plain Java source code and let the engine infer package and class AST definitions. In-memory ClassLoader links cross-class dependencies in RAM with zero disk footprint.

🌐 Cloud-Native REST Microservice

Engineered on Java 21 Loom Virtual Threads for high-concurrency workloads. Exposes production REST endpoints for code compilation (/api/compile), dynamic execution (/api/execute), and tier metrics (/api/tiers).

⚙️ Dynamic Multi-Engine Switching

Clients dynamically select compilation engines per request (via JSON body, query parameter, or HTTP header): standard JAVAC, ultra-low-latency JANINO (<15ms JIT), or Apache Groovy (@CompileStatic).

💾 4-Tier Distributed Bytecode Storage

Chain-of-responsibility persistence hierarchy: RAM / ClassLoader (<1µs) → Redis Cache (<1ms) → Pod Local Volume (2–5ms) → PostgreSQL DB (5–15ms), with automatic upstream cache warming.

📦 Direct Bytecode Streaming & ClassLoader

Remote client JVMs load and execute server-compiled classes dynamically without custom libraries via standard HTTP URLClassLoader streams (/api/classes/...) or Base64 JSON payloads.

🔒 Enterprise Security & AST Sandboxing

Lexical token and AST rule validator proactively rejects unauthorized operations (ProcessBuilder, System.exit, reflection, arbitrary I/O). SandboxedExecutor enforces strict millisecond execution timeout bounds.

Microservice REST API

Compile and execute dynamic Java code over HTTP with virtual thread concurrency.

1

Compile Dynamic Code in RAM

curl -X POST http://localhost:8080/api/compile \
  -H "Content-Type: application/json" \
  -d '{"compiler":"JANINO","source":"package demo; public class Calc { public int add(int a, int b) { return a + b; } }"}'
2

Direct URLClassLoader Bytecode Streaming

URL[] urls = { URI.create("http://localhost:8080/api/classes/").toURL() };
URLClassLoader loader = new URLClassLoader(urls, getClass().getClassLoader());
Class<?> clazz = loader.loadClass("demo.Calc");
