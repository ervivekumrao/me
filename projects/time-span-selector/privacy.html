Privacy Policy

Last updated: June 10, 2026

TimeSpanSelectorView ("the Library") is an open-source Android library.

1. No Data Collection

The Library is a UI component and does not collect, store, or transmit any data from the host application or its users. All time selection operations are performed locally within the application's memory.

2. No Permissions Required

The Library does not require any special Android permissions (e.g., Internet, Storage, Location) to function.

3. Open Source Transparency

The full source code of the Library is available for audit on GitHub. Developers can verify the implementation to ensure it meets their application's privacy standards.
