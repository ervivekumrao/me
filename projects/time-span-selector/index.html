Time Span Selector

A highly customizable and elegant Time Span Selector library for Android. Built with Material 3 principles, offering both Radial (Clock) and Linear selectors for seamless time range input.

View on GitHub

Library Features

🕒 Radial & Linear

Choose between classic clock-style circular selectors or modern linear range sliders to fit your UI needs.

🌙 Overnight Handling

Built-in logic to seamlessly select and display time ranges that cross the midnight threshold.

🎨 Total Customization

Modify colors, widths, thumb styles, and interval snapping (1, 5, 15, or 30 mins) via XML or Kotlin.

📱 Material 3 Ready

Designed for the latest Android design standards with support for dynamic theming and fluid gestures.
