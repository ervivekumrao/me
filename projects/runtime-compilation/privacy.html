Privacy Policy

Last updated: June 10, 2026

RuntimeCompilation ("the Tool") is a developer library for dynamic code execution.

1. No Data Collection

The Tool does not collect, store, or transmit any source code or compiled bytecode. All compilation and execution tasks are performed locally within your application's JVM.

2. Execution Safety

The Tool compiles and executes code as provided by the host application. It is the developer's responsibility to ensure that any dynamically compiled code is safe and does not violate user privacy or system security.

3. Third-Party Sharing

We do not share any information with third parties, as the Tool operates entirely in a local, offline manner within your application context.

4. Contact Us

For any questions, please contact manuscriptcode@gmail.com.
