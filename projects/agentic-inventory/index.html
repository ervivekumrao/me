Microservices Architecture

Polyglot decoupled services communicating over HTTP REST, Kafka event streams, and reactive data pipelines.

☕

inventory-service

Java 17/21 • Spring Boot 3.4.1 • Port 8081

Core transactional engine managing stock items, batch adjustments, immutable audit logs, Spring Security RBAC, Kafka stock mutation events, and Actuator runtime log level management. Pluggable across 5 database dialects.

🍃

catalog-service

Java 17/21 • MongoDB 6.0 • Port 8082

Dynamic document-based product management powered by MongoDB for flexible technical specs, categories, brands, price tiers, and automated bootstrap seeder pipelines.

🤖

forecasting-service

Python 3.11 • FastAPI • Port 8083

Scikit-Learn trained ML intent classifier (1,700+ queries across 15 intents), NER entity extraction, dual-mode Gemini/OpenAI router with offline local ML fallback, and statistical demand forecasting.

🧪

integration-tests

JUnit 5 • Testcontainers • Embedded H2/Mongo

Comprehensive cross-service integration test suite utilizing Testcontainers for real-world validation of transactional stock updates, Kafka event publishing, and AI context hydration.

Deep Technical Capabilities

Engineering highlights extracted directly from the system implementation.

🤖 ML Intent Classifier & NER Engine

Scikit-Learn TF-IDF vectorizer combined with Calibrated Logistic Regression trained on 1,700+ queries across 15 operational intents. Performs dynamic NER extraction for SKUs, warehouse locations, product categories, and top-N filters.

🔄 Dual-Mode AI & Local Fallback

Seamlessly routes to external LLMs (Google Gemini / OpenAI) when configured, with automatic instant fallback to local offline statistical synthesis and deterministic ML logic when offline.

🔌 Pluggable Multi-Database Dialects

Zero vendor lock-in via custom runtime query dialect abstraction supporting PostgreSQL, Microsoft SQL Server, MySQL, Oracle, and IBM DB2 with programmatic transaction boundaries and custom isolation levels.

⚡ Kafka Streaming & Distributed Tracing

Event-driven stock mutation publishing to Apache Kafka. Cross-service correlation ID tracing (X-Correlation-ID) via SLF4J MDC, accompanied by a Web Logging Admin console for runtime log-level adjustments without restarts.

📊 Inventory Science & Safety Stock

Multi-period exponential smoothing, linear trend regression, anomaly detection, statistical safety stock formula ($Z=1.65$, 95% service level), and dynamic Reorder Point (ROP) calculation.

📄 Interactive Web Chat & Multi-Format Export

Web-based AI workspace (/chat.html) featuring real-time markdown streaming and native multi-format exports: Excel (.xlsx via SheetJS), Word (.docx via OpenXML standard), and PDF (.pdf).

🔐 Enterprise Security & RBAC

Spring Security HTTP Basic authentication with BCrypt hashing, domain entities (User, Role, Permission), pre-seeded roles (ROLE_ADMIN, ROLE_MANAGER, ROLE_ENTRY_OPERATOR, ROLE_USER), and administrative user management APIs.

☸️ Cloud-Native Podman, Docker & Helm

One-command environment lifecycle management (/scripts/setup.sh), Podman/Docker Compose configs, rootless Podman Kubernetes manifests, and production-ready Helm charts with ingress routing and health probes.

One-Command Environment Management

Automated deployment lifecycle utility supporting Podman and Docker across 5 relational database profiles.

1

Bootstrap Environment & Database Dialect

Tears down existing volumes, sets up target database engine, compiles services, launches containers, and seeds sample inventory data:

./scripts/setup.sh fresh postgres   # or mysql, mssql, oracle, db2
2

Hot-Reload Microservices

Rebuilds and reloads microservice containers on code changes without interrupting database volumes or Kafka brokers:

./scripts/setup.sh reload forecasting-service
3

Web Interfaces & Operations Dashboards

• AI Agent Chat Workspace: http://localhost:8081/chat.html
• Actuator Logging Admin Console: http://localhost:8081/logging-admin.html
• OpenAPI Docs: http://localhost:8083/docs (Forecasting) • http://localhost:8081/swagger-ui.html (Inventory)
